# University Exam Registration System

## Description
This Java program registers students for examinations and validates their information using exception handling and a custom checked exception.

## Questions and Answers

**1. What is the purpose of `try` and `catch`?**  
`try` contains code that may cause an exception, while `catch` handles the exception.

**2. What is the difference between `throw` and `throws`?**  
`throw` actually throws an exception, while `throws` declares that a method may throw an exception.

**3. What is the purpose of `finally`?**  
`finally` normally executes whether an exception occurs or not. It is commonly used for cleanup operations.

**4. Why create a custom exception?**  
A custom exception allows us to handle application-specific errors, such as invalid student registration information.
